# Nightmare Lab — Halloween Hackathon Landing Page

A polished Halloween-themed 24-hour college hackathon landing page built with **HTML, CSS and vanilla JavaScript**.

## Theme

**Nightmare Lab — Build After Dark**

The visual identity uses Halloween-inspired colors, fog, moonlight, pumpkins, bats, graves, a haunted castle, creepy typography and a dark atmospheric interface.

## Requirements covered

- Hackathon name
- Date and 24-hour duration
- Prize pool
- Halloween theme
- Judges / mentors
- Timeline
- About section
- Rules / eligibility
- FAQs
- Registration CTA
- Responsive desktop/mobile design
- Sticky navigation and mobile menu
- Scroll reveal animations
- Interactive registration form
- Semantic HTML
- Accessibility labels and reduced-motion support

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- No React or framework required

## Run

Open `index.html` in a browser or use VS Code Live Server.
